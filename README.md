# Оно тебе надо

Учебный проект Яндекс Практикума: вёрстка одностраничного сайта аукциона вещей, в которые никто не верил.

## Что внутри

Страница состоит из пяти блоков:

- **Шапка:** меню, логотип и контакты.
- **Обложка:** фоновое изображение с оверлеем, заголовок, подзаголовок и кнопка «Сделать ставку».
- **Лоты:** три карточки с фоновыми картинками и ссылка «посмотреть больше».
- **Об аукционе:** круглый логотип, заголовок и два абзаца.
- **Подвал:** контакты, меню и иконки соцсетей.

## Технологии

- HTML5 с семантической разметкой: `header`, `main`, `section`, `article`, `address`, `nav`, `footer`.
- CSS3: Flexbox, Grid, абсолютное и относительное позиционирование.
- Методология БЭМ для именования классов.
- Шрифт Raleway (подключён через `@font-face`, форматы `woff2` и `woff`).

## Структура проекта

```
.
├── index.html          # разметка страницы
├── fonts/              # шрифты Raleway и fonts.css
├── images/             # фоны, логотипы и иконки соцсетей
└── styles/
    ├── global.css      # сброс браузерных стилей и общие настройки
    └── style.css       # стили проекта
```

## Как запустить

Откройте файл `index.html` в браузере. Сервер и сборка не нужны.

Макет рассчитан на экраны шириной от 1100px.
